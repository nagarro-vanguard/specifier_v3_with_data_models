# Build log

The build status of every item in the four specs. One row per item, in phase order.

The status is one of:
- **not started**
- **built:** written, and waiting for its gate
- **tested:** a program that passes its tests, waiting for its gate
- **gate passed:** you have reviewed it: Phase 1 at its phase gate, every later item at its gate in the trial

Notes marked "For the gate" are still to be answered at the phase gate. "Settled as plumbing" means a choice you would never notice, which I made and you did not object to. After each answer, the spec is updated to match.

At the Phase 1 gate, every template also gained its definition block, a Check record where it has a gate, and placeholders in curly braces, so nothing is hidden when it is read.

After the gate, every shared file was rewritten in plain words, without the interim name, design-page rows or gate answers. That history stays in the specs, and a test keeps it out of the shared files.

Then every template was rebuilt to one standard: nothing hidden, a line under each heading saying what it holds, placeholders that say exactly what to write with an example, the old skills' guidance brought back, and examples about a made-up product only. The Discovery brief was redesigned so that clashes are found by comparing every topic, and hundreds of files are handled.

On 2026-10-21, the point where you decide was renamed the decision review gate, and questions were given one home, the Question log. probing-questions-author drafts and rates each question, and grade-questions.cjs places it in its group, sets the order and checks it. Every template that held open questions now names the question behind each gap. The Glossary's decisions are written once, in the gate log, and two new programs fill the other places from it.

Later on 2026-10-21, every Phase 1 item was reviewed again, one sitting at a time, and accepted. Phase 1's gate is passed.

On 2026-10-22 you decided to build everything first, then run the whole flow once, as a trial on your requirement. From Phase 2 on, each program is tested on test data while it is built, and its gate is held in the trial. Choices made while building are listed in MASTER-PLAN section 8, "Calls made while building".
